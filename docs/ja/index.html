選ばれる6つの理由

🧩 スマート文章結合（チラつき防止）

2〜3単語ごとに途切れる自動字幕を、句読点や文脈に基づいて完全な1文に再構築してから翻訳。[Music] 等のノイズも自動除去し、テレビ字幕のように安定した二ヶ国語表示を実現します。

🔍 選択単語の辞書 ＋ 🎬 原音再生

字幕上の気になる単語やフレーズをマウスでなぞるだけで意味を表示。「🎬 原音を聴く」を押せば、動画内のスピーカーがその単語を発音した瞬間の音声だけを切り抜いてリピート再生します！

⚡ R / A / D シャドーイング熱キー

リスニング＆スピーキング練習に最適：R キーで現在の1文の原音をリプレイ（文末で自動一時停止）、A で前の文、D で次の文へ瞬時にジャンプできます。

🚀 45秒先読み＆60fps ゼロ遅延同期

45秒先の字幕までバックグラウンドで事前翻訳。2倍速以上の高速再生やシークバー移動でも、翻訳待ちの遅延なく瞬時に同時字幕が表示されます。

🎯 標準 [CC] ボタン連動で邪魔しない

日本の動画や音楽を見るときに勝手に字幕が出ることはありません！YouTube 右下の [CC] 字幕ボタンをオンにした時だけスマートに二ヶ国語字幕が起動します。

📱 YouTube ショート (Shorts) 完全対応

YouTube ショートの縦画面レイアウトを自動判別し、タイトルやいいねボタンに被らない最適な位置にデュアル字幕を表示します。

よくある質問 (FAQ)

Q1: インストール後、どうやって二ヶ国語字幕を表示しますか？

字幕のある YouTube 動画を開き、プレーヤー右下の [CC]（字幕） ボタンをオン（赤い下線が表示された状態、またはキーボードの C キー）にするだけで自動的に二ヶ国語字幕が表示されます！

Q2: どの言語に翻訳できますか？

日本語、英語、繁体字中国語、簡体字中国語、韓国語、スペイン語、フランス語、ドイツ語、ベトナム語、タイ語の計10言語への相互翻訳に対応しています。

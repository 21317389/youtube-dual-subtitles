為什麼選擇這款 YouTube 雙語字幕擴充功能？

🧩 雙軌智慧整句重組 (防跳行)

YouTube 自動字幕每 2～3 個字就斷行滾動，導致傳統翻譯外掛頻繁閃爍。我們自動清洗 [Music] 等雜訊，將碎詞重組為完整句子，並以「上槽歷史句、下槽活躍句」穩定呈現。

🔍 反白查詞 ＋ 🎬 講者原聲重播

滑鼠反白字幕上任意生詞即彈出翻譯浮窗。點擊「🎬 聽原聲」直接倒轉並精準截取影片中講者說出該單字的真實語音切片重播，比機械 TTS 發音更道地！

⚡ R / A / D 聽力跟讀快捷鍵

專為語言學習 Shadowing 打造：按 R 重播當前句子原聲（播完自動暫停）、按 A 跳上一句、按 D 跳下一句，還支援滑鼠懸停字幕自動暫停影片。

🚀 45 秒預載 & 60fps 零延遲同步

採用主環境同源 InnerTube 高速通道與 45 秒滑動視窗預先翻譯，即使開 2x～16x 倍速看課程，雙語字幕依然零延遲、零單行塌陷。

🎯 尊重原生 CC 開關・日常零打擾

預設絕不強開字幕！僅在您開啟 YouTube 播放器右下角原生 [CC] 按鈕時才渲染雙語字幕；看母語影片或聽音樂時完全不干擾。

📱 原生支援 YouTube Shorts

自動偵測 YouTube Shorts 短影音垂直版面並智慧調整字幕高度，絕不遮擋影片標題與互動按鈕，滑短片也能輕鬆學外語。

常見問題 (FAQ)

Q1: 安裝後怎麼啟動 YouTube 雙語字幕？

打開任何有字幕的 YouTube 影片或 Shorts，點擊播放器右下角的原生 [CC] 按鈕（底部紅線亮起，或按鍵盤 C 鍵），雙語字幕就會立即啟動！若想暫時看回單語字幕，只需點擊右上角外掛圖示關閉總開關即可。

Q2: 支援哪些翻譯語言？

支援將任何 YouTube 外語字幕即時翻譯為 10 種語言：繁體中文、簡體中文、英文 (English)、日文 (日本語)、韓文 (한국어)、西班牙文 (Español)、法文 (Français)、德文 (Deutsch)、越南文 (Tiếng Việt) 與泰文 (ไทย)。

Q3: 支援 Microsoft Edge、Brave 或 Arc 瀏覽器嗎？

完全支援！所有 Chromium 核心瀏覽器（Chrome、Edge、Brave、Arc、Vivaldi）皆可直接點擊上方 Chrome 線上應用程式商店按鈕一鍵安裝使用。
